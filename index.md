# Amit Portal

A curated list of public projects by amitportal on GitHub.

## Projects

- [language_detector](https://github.com/amitportal/language_detector)  
  A fully documented, cache-aware advanced_script_detector.py. Recognises 10 Indic scripts plus English, reports a confidence score, and can auto-learn high-certainty words.

- [similar_column_merge_tool](https://github.com/amitportal/similar_column_merge_tool)  
  Uses AI embeddings to detect matching columns between two CSV files and automatically merges them to resolve semantically similar column names.

- [DIU-Mapping](https://github.com/amitportal/DIU-Mapping)  
  Mapping utilities and scripts (project files). See repository for notebooks and utilities.

- [india_internal_migration_mapping](https://github.com/amitportal/india_internal_migration_mapping)  
  Visualisations and mapping of internal migration in India. Contains HTML front-end and Python scripts for data processing.
